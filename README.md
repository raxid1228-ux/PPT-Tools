🌟 ئالاھىدە PPT تەييارلاش قۇرالى (Special PPT Preparation Tool)

بۇ تۈر ئۇيغۇر تىلىدىكى دىنىي، تەلىم-تەربىيە ۋە لېكسىيە مەزمۇنلىرىنى ئاسانلا كۆركەم سىلايىد (PPT) ھالىتىگە ئۆزگەرتىپ كۆرسىتىپ بېرىدىغان، تولۇق بىر گەۋدىلەشتۈرۈلگەن بىرلا بەتلىك تور قورالىدۇر (Single-file HTML App).

🚀 ئاساسلىق ئالاھىدىلىكلىرى

🕌 ئايەت ۋە ھەدىس تونۇش: قۇرئان ئايەتلىرى ۋە ھەدىس-شەرىپلەرنى ئاپتوماتىك پەرقلەندۈرۈپ، ئەرەبچە تېكىستى ۋە ئۇيغۇرچە تەرجىمىسىنى ئالاھىدە گۈللۈك رامكىدا كۆرسىتىدۇ.

🎨 4 خىل ئېسىل ئۇسلۇب (Theme): مودا (Trendy)، سىپتا (Sleek)، ئىسلامىي (Islamic) ۋە ھەرىكەتچان (Dynamic) ئۇسلۇبلىرى ئارىسىدا خالىغانچە ئالмаشتۇرغىلى بولىدۇ.

🤖 سۈنئىي ئىدراك بۇيرۇقى: تەييار بۇيرۇق (Prompt) ئارقىلىق سۈنئىي ئىدراكتىن خالىغان تېمىدا مۇۋاپىق دەرىس مەزمۇنىنى ئاسانلا ھاسىل قىلغىلى بولىدۇ.

📂 JSON ساقلاش ۋە يۈكلەش: تەييارلانغان دەرىشلەرنى JSON ھۆججىتى شەكلىدە كومپيۇتېرىڭىزغا ساقلاپ، كېيىن قايتا يۈكلەپ ئىشلىتەلەيسىز.

⛶ پۈتۈن ئېكران ۋە ئاسان كونترول: پۈتۈن ئېكران ھالىتىنى قوللايدۇ، كۇنۇپكا (Keyboard) ياكى چاشقىنەك ئارقىلىق قەدەممۇ-قەدەم ئالغا ئىلگىرىлейدىغان ھەرىكەتچان ئۈنۈملەرگە ئىگە.

🛠️ ئىشلىتىش ئۇسۇلى

بۇ HTML كودىنى كومپيۇتېرىڭىزغا ساقلاڭ (مەسىلەن: index.html).

ھۆججەتنى خالىغان توركۆرگۈدە (Chrome, Safari, Edge) بىۋاسىتە ئېچىڭ.

1-قەدەمدىكى بۇيرۇقنى كۆچۈرۈپ سۈنئىي ئىدراكقا بېرىڭ ھەمدە كەلگەن نەتىجىنى ئاساسلىق كۆزنەككە چاپلاپ «دەرىس باشلاش» كۇنۇپكىسىنى بېسىڭ.

💻 تېخنىكىلىق ئالاھىدىلىكلىرى

پۈتۈنلەي ساپ HTML5, CSS3 (Glassmorphism & Flexbox) ۋە JavaScript ئاساسىدا يېزىلغان.

ھېچقانداق سىرتقى مۇلازىمېتىر ياكى قوشۇمچە قاچىلاشنى تەلەپ قىلمەيدۇ.
